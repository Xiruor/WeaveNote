/* 1. 容器按单帧尺寸限制，背景横向铺开 N 倍 */ .zhibao { width: 460px; height: 482px; background: url("zhibao-sprite.png") 0 0 / 7360px 482px no-repeat; animation: play 1.6s steps(16) infinite; /* 16 帧 → 10fps */ } /* 2. 位移恰好等于整张图宽度，steps 把过程切成 16 格 */ @keyframes play { from { background-position-x: 0px; } to { background-position-x: -7360px; } }

小尺寸复用只需缩放：容器宽高与 background-size 同步乘以系数（示例里 --s: .19）。 整张图 7360×482，RGBA 透明背景，单文件 3.6 MB。
